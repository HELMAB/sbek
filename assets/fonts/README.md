# Fonts

Khmer-script subsets (woff2) of:

- **Battambang** 400 / 700 — Copyright 2019 The Battambang Project Authors (https://github.com/danhhong/Battambang)
- **Koulen** 400 — Copyright 2019 The Koulen Project Authors (https://github.com/danhhong/Koulen)

Both are licensed under the SIL Open Font License 1.1 (`OFL.txt`). Files were taken from Google Fonts
and are self-hosted so visitors' browsers never contact a third-party font CDN.
Latin text deliberately falls back to Arial (see `--font-sans` in `assets/css/src/input.css`).
